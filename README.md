# Portfolio

Статический сайт-портфолио. Никакой сборки не нужно — открывается как есть,
деплой на GitHub Pages.

## Картинки

Оригиналы лежат в `source/img/`. Напрямую на страницах они **не показываются** —
там слишком большой вес (например `nerf.png` это 4.7 МБ). Вместо них
`tools/build-images.py` собирает три производных версии:

| Папка                | Размер   | Зачем                                              |
| -------------------- | -------- | -------------------------------------------------- |
| `source/img/low/`    | ~64 px   | плейсхолдер на 1–2 КБ, виден мгновенно, размывается через CSS |
| `source/img/thumb/`  | ~400 px  | мелкие ячейки сеток (миниатюры колоды карт)        |
| `source/img/opt/`    | ~1600 px | то, что реально показывается на странице           |

Анимации (GIF, APNG) вместо картинок превращаются в `mp4` — они весят в
20–100 раз меньше. Для видео в `low/` складываются постеры-первые кадры.

### Как добавить новую работу

1. Положить оригинал в `source/img/`.
2. Прописать её в нужном html — по образцу соседних блоков:

   ```html
   <img class="progressive-img"
        src="../source/img/low/ИМЯ.png"
        data-src="../source/img/opt/ИМЯ.webp"
        data-fallback="../source/img/ИМЯ.png"
        width="1216" height="1802" decoding="async" alt="описание">
   ```

   `width`/`height` — настоящие пиксели оригинала: браузер по ним заранее
   резервирует место, и страница не прыгает при загрузке.

3. Собрать производные версии:

   ```sh
   python3 tools/build-images.py          # только новое и изменившееся
   python3 tools/build-images.py --force  # пересобрать всё заново
   ```

Скрипт сам находит все картинки, на которые ссылается html, так что порядок
шагов 2 и 3 не важен. Нужны `Pillow` и `ffmpeg`.

Имя файла в `low/` всегда совпадает с именем оригинала (включая расширение) —
раньше часть плейсхолдеров была сохранена как `.png` при оригинале `.jpg`,
из-за чего ссылки вели в пустоту.

## Загрузка

`js/lazy-media.js` подгружает тяжёлую версию только когда картинка подходит к
экрану, и не больше четырёх штук одновременно. Видео стоят на `preload="none"`
и запускаются тоже по появлению в кадре, а за пределами экрана ставятся на паузу.
